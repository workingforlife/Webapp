JSON Repair and Formatter

Paste broken JSON from ChatGPT, Claude or any model. Fix trailing commas, single quotes, unquoted keys, comments, code fences and cut-off output, and see every change made.

Runs in your browser. Nothing you enter is uploaded.

Next: Validate the result against a schema JSON Validator

How to Use

  1. Paste the broken JSON, or pick one of the example problems.
  2. Read the list of changes, and check any that were guesses.
  3. Choose a layout, then copy or download the repaired JSON.

What It Is For

Models asked for JSON often return something that almost parses: wrapped in a Markdown code fence, introduced by a sentence, ended with a trailing comma, written with Python-style quotes, or cut off when the reply hit its length limit. This tool repairs those cases in your browser and lists each change, so you can see exactly what was touched. It also formats valid JSON, with the indent you choose and optional key sorting.

What It Fixes

  • Markdown code fences and text before or after the JSON
  • Comments (// and /* */)
  • Single quotes, curly quotes and unquoted keys
  • Trailing commas and missing commas between items
  • True, False and None from Python
  • Line breaks and tabs typed inside strings, and invalid escapes
  • Number formats such as a leading plus sign, .5 or leading zeros

When It Has To Guess

Some repairs are guesses, and the tool lists them in a separate "Check these" section. Closing the brackets of cut-off output, dropping an unfinished last item, and replacing NaN, Infinity or undefined with null all change what the data means or how much of it there is. Cut-off output is missing whatever the model never wrote, so check any repaired result before you rely on it.

What It Does Not Do

  • It does not check your data against a schema. Use the JSON Validator for that.
  • It does not fix unescaped double quotes inside a string, because the right fix is ambiguous. It reports an error instead.
  • It cannot recover content that was never produced. See how to get reliable JSON from an LLM.

Frequently Asked Questions

Is my JSON uploaded?

No. Repair and formatting run in your browser, and the page does not send your text anywhere.

Does it change my data?

Formatting and the safe fixes keep every value as written, including long numbers and duplicate keys. The guesses listed under "Check these" can change data, so they are called out.

Why did it say it could not repair my JSON?

It stops when it cannot tell what you meant, for example a stray character where a key or value should be. The message gives the line and column.

Can it fix JSON with unescaped quotes inside a string?

No. A quote inside a string can be the end of the string or part of the text, and guessing wrong silently corrupts the data. Escape it as \" in the source, or ask the model to escape quotes.
